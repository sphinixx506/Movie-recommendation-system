# Movie-recommendation-system

## Overview
This project is a content-based movie recommendation system that suggests similar movies based on user input using NLP and and the similarities between the vector of the movies.

## Technologies Used
- Python
- Pandas
- Scikit-learn
- CountVectorizer

## Features
- Recommends top 5 similar movies
- Uses movie metadata (overview, genres, keywords)
- Handles invalid input

## Example
Input: Inside out,Tangled,Harry Potter,Slumdog Millionaire 
Output: List of recommended movies/Movie not found.

## Dataset
TMDB Movie Dataset (Kaggle)
